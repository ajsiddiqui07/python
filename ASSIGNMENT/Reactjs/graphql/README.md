# React / Next.js Assignments — Sessions 4 to 10

This bundle contains seven independent projects. Each session folder contains its own project and README.

| Session | Project | Main topics |
|---|---|---|
| 4 | `myapp` | Apollo Client mutations, optimistic UI, playlist count |
| 5 | `playlist-graphql` | GraphQL schema, nested query, duration, introspection |
| 6 | `insta-feed` | Next.js Pages Router, SSR explanation |
| 7 | `playlist-routing` | File routing, dynamic routes, SSG paths |
| 8 | `next-data-fetching` | getStaticProps, getServerSideProps, dynamic SSG |
| 9 | `nextauth-google` | NextAuth Google, protected API, profile, logout |
| 10 | `insta-news` | Next.js API, GraphQL-style endpoint, Firebase Google login, OpenAI summaries |

## General setup
Open the relevant project folder in VS Code, run `npm install`, then follow that session's README. Do not run `npm install` at this root folder.

## Notes
- Credentials are not included. Configure your own `.env.local` files using the supplied `.env.local.example` templates.
- Session 4 and 5 include runnable local GraphQL servers.
- Session 8 uses mock/local sample data where the task allows it.
- Session 10 uses a small GraphQL-compatible practice endpoint for the specified static sample posts.
- These are learning projects. Review environment variables, provider settings, and server validation before production use.
